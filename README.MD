# Игра «5 букв»

Консольная игра в духе Wordle. Программа выбирает слово из словаря, а игрок пытается его угадать за ограниченное количество попыток.

После каждой валидной попытки игрок получает подсказку по каждой букве:

- ✅ — буква стоит на правильном месте;
- 🟡 — буква есть в загаданном слове, но стоит на другом месте;
- ❌ — такой буквы среди оставшихся букв загаданного слова нет.

Пример:

Загадано: `озеро`  
Ввод: `арбуз`

Результат:

`❌🟡❌❌🟡`

---

## Что реализовано

### Словарь

Слова загружаются из файла `dictionary.txt`.

При загрузке:

- пропускаются пустые строки;
- используются только слова длиной 5 букв;
- слова приводятся к нижнему регистру;
- пустой словарь считается ошибкой.

После загрузки словарь предоставляется игровой логике только для чтения.

### Выбор слова

Загаданное слово выбирается случайно из словаря.

Для генератора используется `seed`, поэтому одинаковый словарь + одинаковый `seed` → одинаковое загаданное слово.

### Игровая сессия

`GameSession` хранит состояние одной партии:

- загаданное слово;
- максимальное количество попыток;
- количество использованных попыток;
- историю валидных попыток;
- текущий статус игры:
    - `InProgress`;
    - `Win`;
    - `Lose`.

Невалидный ввод не изменяет состояние сессии и не расходует попытку.

После завершения партии новые попытки не принимаются.

### Валидация попытки

Перед применением попытки проверяется:

- ввод не пустой;
- слово состоит ровно из 5 символов;
- все символы являются буквами;
- слово присутствует в словаре.

Ввод не зависит от регистра:

`ОЗЕРО` и `озеро` обрабатываются одинаково.

### Проверка букв

Для каждой буквы определяется один из статусов:

- `OnCorrectPlace`;
- `OnWrongPlace`;
- `NotContained`.

Повторяющиеся буквы обрабатываются в два прохода: сначала ✅, затем 🟡. Каждое вхождение буквы 
ответа используется не более одного раза. Сначала отмечаются буквы, стоящие на правильных местах, 
а затем оставшиеся буквы используются для определения статуса `OnWrongPlace`.

Например:

Загадано: `сорок`  
Ввод: `оооом`

Результат:

`❌✅❌✅❌`


### Завершение игры

Игра завершается:

- победой, если пользователь угадал слово;
- поражением, если закончились доступные попытки.

При поражении пользователю показывается загаданное слово.

## Архитектура

Игровая логика отделена от консольного ввода и вывода.

### `GameSession`

Хранит состояние конкретной партии и изменяет его после валидной попытки.

### `GameEngine`

Содержит правила применения попытки:

- нормализует ввод;
- проверяет корректность слова;
- проверяет наличие слова в словаре;
- не позволяет изменять завершённую партию;
- применяет валидную попытку к `GameSession`;
- получает результат проверки букв.

### `GuessChecker`

Отвечает только за сравнение введённого и загаданного слова.

Не зависит от консоли и состояния партии.

### `GuessResult`

Передаёт результат обработки попытки из игровой логики в интерфейс:

- тип результата;
- статусы букв для валидной попытки.

### `ConsoleGame`

Отвечает только за консольный интерфейс:

- чтение пользовательского ввода;
- отображение ошибок;
- отображение статусов букв;
- отображение количества оставшихся попыток;
- сообщения о победе и поражении.
